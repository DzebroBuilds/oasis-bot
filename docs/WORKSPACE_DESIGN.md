# Unified OASIS workspace

A final shared workspace-theme.css import in App applies a matte neutral background, consistent muted type, one accent color, thin dividers, small control radii and flat metric rows across the existing component styles. No additional dependencies.

Flow: compact introduction, workspace anchor navigation, active round and quotes, ambient OASIS core with command briefings and pulse, analysis, sources and settlement details, general market browser. The sample profile is preserved inside a collapsed details disclosure.

The visual core fades into the shared surface instead of sitting inside a rounded card. Analysis and sources use continuous sections. General market cards become divided metric rows; filters and tabs use the same controls. Mobile collapses the core sidebar and keeps compact quote columns. Trading, discovery, calculations and source data are unchanged.
