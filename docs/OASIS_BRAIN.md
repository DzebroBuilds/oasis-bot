# OASIS Brain

The interactive workspace displays real received public contract data. Select an input to inspect its role, choose 10 or 30 observations, scrub the snapshot slider, or follow the latest quote. Replay changes only the historical detail; the current lean remains based on the latest valid quote. Best-level bid/offer depth is resting quantity, not a forecast or total order-book imbalance.

Animations indicate an open, fresh connection, never artificial model activity. Reduced motion respects the OS preference and a local button. All controls support keyboard operation. News and the calculation explanation remain below the brain. No order execution is added.

The pulse history is browser-session data, resets on round change, and omits missing two-sided prices. It is contract sentiment, not a BTC spot chart. The existing freshness, spread, outcome-mapping and expiry checks continue to gate the lean.
