How it works
Six steps, zero manual effort.
⏰

Scheduled scan

GitHub Actions fires Oasis every 6 hours automatically. No server needed — runs entirely on GitHub's free tier.

🔍

Market discovery

Oasis queries all open Kalshi sports markets closing in the next 48 hours across every major league.

🧠

AI research

Gemini Flash analyzes each matchup — recent form, H2H, injuries, home advantage, and market pricing edge.

📊

Confidence scoring

Every pick is scored 0–100. Only picks scoring 90%+ with a 10+ point market edge qualify for trading.

💰

Autonomous trade

Qualifying picks are placed directly on Kalshi via the REST API, with daily spend caps enforced automatically.

📱

Instant alerts

Every trade, win, and loss fires a Telegram notification in real time. Full P&L tracked on the live dashboard.

Technology
Built entirely on free APIs.
Google Gemini Flash FREE
AI research engine. 1,500 free requests/day via Google AI Studio. Analyzes each matchup across 9 data points and returns a structured confidence score.
Kalshi API
CFTC-regulated prediction market. Oasis uses the official REST API to browse markets, check prices, and place limit orders programmatically. Legal in Washington state.
GitHub Actions FREE
Serverless scheduler. Runs the full agent on a cron schedule every 6 hours with zero infrastructure cost. Secrets stored in encrypted GitHub vault.
Telegram Bot API FREE
Real-time push alerts to your phone for every trade placed, won, or lost. Daily summary delivered each morning with full session stats.
